# 电磁感应 感应电路与电势测量

使用 XeLaTeX 连续编译两次 `main.tex`，或使用 `latexmk -xelatex main.tex`。全部知识图、题设图与解答过程图保留为可编辑 TikZ。

- `theory.tex`：知识讲解、推导、适用条件和知识图。
- `examples.tex`：例题、题设图、分步解答与过程图。
- `summary.tex`：本讲小结。
- `practice.tex`：练习及题设图。
- `answers.tex`：练习的集中分步详解与过程图。
- `lecture-style.tex`：与整套一致的公共样式。

额外的 `.tex` 文件由主文件按需引用；编译时保留同目录的全部源码。图号、题号及内部跳转在编译时自动更新。
